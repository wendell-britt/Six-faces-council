# Architect Decision — Represent the Source, Trace the Movement

`TensionVector` should denote only a purpose-bound, versioned, lossy representation of a dissatisfied configuration. A separate `TransformationTrajectory` links source representation, practice, transformation finding, resulting-state report, action intention, artifact, and consequence.

The current object is a semantic feature bundle with attraction and avoidance, not a mathematical vector. Formal records require source reports, encounter, derivation method and version, purpose, field manifest, omissions, uncertainty, player-correction status, privacy scope, retention, and permitted uses.

Legacy snapshots must be described as actually stored; absent fields must not be backfilled through inference.
