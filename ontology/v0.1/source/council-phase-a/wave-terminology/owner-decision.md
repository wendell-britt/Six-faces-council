# Owner Decision — Basic Moves and WAVE Terminology

**Decision date:** 2026-10-10
**Authority:** Wendell Britt, ontology owner
**Status:** Canonical terminology correction

## Decision

The five practices below are called the **Basic Moves**:

1. Wake Up
2. Open Up
3. Clean Up
4. Grow Up
5. Show Up

**WAVE** is reserved for the breathing practice associated with **Open Up**. It is not the name of the five Basic Moves and it is not the name of the four-stage progression used within an Emotional Alchemy channel.

The Emotional Alchemy progression `Wake → Clean → Grow → Show` is provisionally named the **within-channel progression** in this ontology package. This neutral label prevents collision without inventing a new canonical title. A later source-authorized name may replace it.

The **fifteen canonical Emotional Alchemy moves** remain a third, distinct structure: five Transcend moves, five Generative translations, and five Control translations.

## Canonical distinctions

| Structure | Members or function | Correct name |
|---|---|---|
| Personal practice set | Wake Up, Open Up, Clean Up, Grow Up, Show Up | Five Basic Moves |
| Open Up practice | Breathing practice | WAVE |
| Element/channel process | Wake, Clean, Grow, Show | Within-channel progression |
| Emotional Alchemy move grammar | Five Transcend, five Generative, five Control | Fifteen canonical moves |

The structures may interact, but shared words do not make them the same object.

## Deprecated usages

The following phrases are incorrect or legacy terminology and must not be taught as current canon:

- “five WAVE moves”;
- “WAVE order” for the five Basic Moves;
- “elemental WAVE”;
- “WAVE progression per element” or “inside each channel”;
- “complete WAVE” when referring to Wake → Clean → Grow → Show.

Historical ingestion and crosswalk records may retain these phrases as evidence of what the council encountered. Current retrieval must pair those records with this correction and treat the earlier terminology as superseded.

Runtime names such as `wave`, `MOVE_TO_WAVE`, or `submove` are legacy implementation identifiers until separately audited. Their continued presence in code does not grant them canonical naming authority, and they must not be mechanically renamed without checking APIs, stored data, authored content, and tests.

## Limits of this decision

This decision fixes names and category boundaries. It does not define the steps or acronym expansion of the WAVE breathing practice, change the fifteen-move grammar, or resolve unrelated Emotional Alchemy questions about satisfaction, completion, or application fitness.

## Source relation

Wendell indicated that the fuller account is already substantially covered by the *Mastering the Game of Allyship* book. Until the relevant book passage is ingested as a source, this owner statement governs terminology while the practice details remain unspecified here.
