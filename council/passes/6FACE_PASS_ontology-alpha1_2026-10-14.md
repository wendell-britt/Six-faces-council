Wendell called this pass on 2026-10-14 in the design-ontology project chat: “yes let's do that. Let's have the 6 game masters guide us through this process.” The question is how to move the merged ontology into a usable repo-local alpha for real game-design work without beginning Phase B sorting. This is the first pass on alpha shipping.

## Scorecard

The 2026-10-12 shipping assessment named nine alpha deliverables. The manifest, compact Quickstart, design-ontology skill, routed source selection, compatibility aliases, binding-decision registry, and initial tests now exist. Explicit six-face packaging, semantic comprehension fixtures, a real design cycle, clean-session installation proof, and current release documentation remain incomplete. The earlier 55% repo-local-alpha figure is therefore stale; this pass replaces percentage prediction with evidence gates.

## Anchor

The alpha should let a designer give the Six Faces one real game-design question and receive a sourced, ontology-conforming, implementation-ready brief that preserves player authorship, evidence limits, consent, refusal, provenance, and dissent. The process should itself be playable enough that Wendell and another designer would choose to use it again.

## Shaman

**Emergence becomes Fellowship.** This work has landings that cannot be skipped. The first crossing is exposed; the branch has to hold before the flock moves on. The ontology becomes real when six distinct lenses and a designer meet around one playable object.

**The alpha needs an inhabited crossing.** A release page cannot substitute for the felt experience of designing with the ontology. The first cycle uses fictional, non-sensitive material and must produce one concrete design change attributable to the council. The encounter remains playable with refusal, symbolic input, no reported shift, and no disclosure escalation (`ontology/v0.1/QUICKSTART.md`, “Session depth, performance, and disclosure”).

**The standing test remains active.** If the feature interprets reluctance, silence, refusal, or no-shift as something wrong with the player, the alpha fails (`council/faces.yaml`, `faces.shaman.standing_test`).

## Architect

**Overload has no changing lines.** The ridgepole is carrying too much. The answer is not another conceptual storey; it is to redistribute load and prove the existing frame.

**Three gates carry the release.** First, one dogfood cycle produces an implementation-ready encounter brief. Second, observed failures become explicit face contracts and adversarial fixtures. Third, a clean checkout discovers the package, repeats the task without this conversation, and supports truthful release documentation. The current manifest and Quickstart already provide positive source selection; the remaining load-bearing gaps are semantic rather than encyclopedic (`ontology/manifest.yaml`; `ontology/v0.1/source/claude-code-ontology-shipping-readiness.md`).

**The smallest real task is a consent-aware Roadblock Encounter.** A player declares a modest fictional destination and blocking condition; the design separates observation from causal hypothesis, offers preset, symbolic, or self-authored input, includes rest and refusal, supports shift/no-shift/uncertainty/reinterpretation/refusal/unassessed findings, and makes any take-away artifact optional. This stresses the ontology without requiring a whole game or real player data.

## Challenger

**Serendipity becomes Mutuality.** One compelling encounter with the package can create premature confidence. Contain the useful finding, then require the ontology and the design to alter one another.

**Five tests resolve five blockers.** The real-cycle test determines whether the package can carry design work and unlocks freezing the alpha response contract. Adversarial fixtures determine whether fluent answers conceal prohibited collapses and unlock a bounded reliability claim. The face-distinction rerun determines whether six labels produce distinct lenses and unlocks agent packaging. The clean-session test determines whether success depends on this chat and unlocks the repo-local-alpha claim. The scope-pressure test determines whether shipping becomes endless ontology expansion and unlocks release when the bounded gates pass.

**Every added test must unlock a decision.** Stop if a face claims reserved authority, a clean session needs oral repair, a fixture permits a prohibited collapse, or the design cannot produce a smallest meaningful loop (`council/faces.yaml`, Challenger lesson dated 2026-10-03).

## Regent

**Reserves becomes Retreat.** The corpus has accumulated enough strength; now it must be spent under governance. Retreat is the disciplined refusal to let more ontology expansion consume the shipping window.

**Five stages govern the work.** Stage 0 charters one consequential, finishable, non-sensitive feature. Stage 1 runs one design cycle and records friction without silently repairing the ontology. Stage 2 converts observed failures into face contracts, fixtures, and validators. Stage 3 verifies a fresh checkout with no inherited conversation. Stage 4 replaces stale readiness claims with evidence, installation instructions, known gaps, and an alpha tag.

**The ship gate is evidence, not completeness.** Ship only when the real cycle is useful, the fixtures pass, faces remain bounded, clean-session discovery works, validators pass, and documentation describes actual behavior. Do not ship if historical material is selected as canon, Sage decides, a face invents owner belief, real player data is used without enforcement, or Phase B sorting enters scope.

## Diplomat

**Mutuality becomes Drained.** The alpha becomes useful through reciprocal contact, but explaining, packaging, and perfecting everything at once will empty the basin.

**One doorway should contain the work.** The promise is: give the Six Faces one real design question; receive a sourced brief that distinguishes experience, behavior, relationship, and system, preserves dissent, and names what remains provisional. The alpha does not certify a game, diagnose a player, enforce privacy in software, or settle every ontology question.

**The real cycle is the spine.** Each misunderstanding becomes a fixture; each blurred voice becomes a face-contract requirement; each discovery failure becomes a clean-session test; the final brief becomes the release example. Use one review surface, one design question, one council run, one revision, and one release decision. Other insights may be preserved without becoming obligations.

## Sage

**Estrangement becomes Home Field Advantage.** The readiness judgment was made from inside a repository whose rules and history were already familiar. A clean user enters an arrangement built before they arrived. The alpha test must therefore move outside our home-field knowledge.

**The synthesis keeps every face.** Shaman supplies the inhabited crossing and refusal test. Architect supplies the three evidence gates and the Roadblock Encounter. Challenger supplies falsification tests tied to release decisions. Regent supplies obligations, stop conditions, and the three-PR boundary. Diplomat supplies the single doorway and anti-exhaustion covenant. Nothing is dropped.

The smallest coherent whole is three bounded PRs around one spine:

1. charter and run the fictional consent-aware Roadblock Encounter, preserving failures and the resulting design contract;
2. package the six faces and convert observed plus known failures into adversarial fixtures and validators;
3. verify a clean session, update release documentation, and tag only the passing alpha.

This is an alpha-shipping strand, not Phase B governance. Unresolved ontology questions stay explicit and provisional unless the real cycle proves one blocks use.
