# Plan: Design ontology alpha shipping

## Approach

Use one fictional Roadblock Encounter as the spine of the release. First make the current ontology carry a real design decision and preserve every friction. Then package only the face distinctions and semantic checks the cycle proves necessary. Finally repeat the run from a clean session and publish release truth. This keeps packaging coupled to demonstrated use while separating the work into reviewable PRs.

## Files touched

| Area | Change |
|---|---|
| `.specify/specs/ontology-alpha-shipping/` | Charter, specification, plan, tasks, and dogfood evidence |
| `council/passes/` | Six-face alpha-shipping deliberation |
| `.claude/agents/` | Explicit Shaman–Sage packages in PR 2 |
| `.claude/skills/` | Shared council output and routing contracts as observed |
| `tests/` and ontology validation tools | Adversarial fixtures and structural checks in PR 2 |
| `ontology/` and release documentation | Current readiness, install/use guidance, example, and known limits in PR 3 |

## Order

1. Run the cheap falsification on the Roadblock Encounter.
2. Complete the implementation-ready dogfood brief and record friction.
3. Review and merge PR 1: real-cycle case and contract.
4. Build explicit face packages, semantic fixtures, and validators from the case.
5. Rerun the same prompt twice and preserve differences and dissent.
6. Review and merge PR 2: council packaging and hardening.
7. Verify discovery and use from a clean checkout/session with no inherited chat.
8. Replace the stale readiness report and publish install/update/known-gap documentation.
9. Review and merge PR 3, then tag the exact passing commit `0.1.0-alpha.1`.

## What Wendell does, and when

No action is required before the build. The council reach test resolved Stage 0 from existing authority and Wendell's explicit authorization. Any later question that genuinely requires personal preference, canonical prose, consent, money, or owner authority goes to the board rather than this chat.
